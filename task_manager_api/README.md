# TaskManager API

Backend RESTful API cho ứng dụng quản lý công việc TaskManager được xây dựng bằng Node.js, Express và MongoDB.

## Cài đặt & Chạy ứng dụng

1. Cài đặt các gói phụ thuộc:
   ```bash
   npm install
   ```

2. Cấu hình biến môi trường:
   - Tạo file `.env` từ file `.env.example`
   ```bash
   cp .env.example .env
   ```

3. Khởi chạy ứng dụng (Development):
   ```bash
   npm run dev
   ```

4. Khởi chạy ứng dụng (Production):
   ```bash
   npm start
   ```
